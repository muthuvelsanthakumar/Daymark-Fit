# Privacy policy draft — Daymark Fit

Daymark Fit is designed to work without an account. The intended release architecture stores activity history, routines and preferences locally on the user's device. No account, advertising profile or mandatory cloud synchronization is part of the product design.

## Permissions

The finished app may request physical-activity permission for step counting and location permission while recording GPS activities. Location should be used only for activity tracking features the user starts.

## Exports

Users may choose to export reports or backups to a location they control. Exported files can contain personal activity information and should be handled carefully.

## Maps and network activity

The current GPS-only workout screen does not load map tiles or require a map provider. GPS coordinates are acquired from the device location services and saved locally. The app may request network access for standard platform/build behaviour, but workout recording is designed not to depend on internet connectivity.

## Current status

This is a development draft, not a verified statement about a completed production build. Before public release, update this document to match the exact code, dependencies, map provider and data flows that ship. Do not publish it as final until that review is complete.
